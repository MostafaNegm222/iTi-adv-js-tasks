# ITI Advanced JavaScript Tasks

## 1. Description

Solutions for ITI's advanced JavaScript tasks, organized by day (day 1 to day 4).

## 2. Technologies and Versions

- HTML5, vanilla JavaScript (no build step)

## 3. Requirements and Dependencies

- A modern web browser
- No packages to install

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/iTi-adv-js-tasks.git
cd iTi-adv-js-tasks
```

Open the HTML files inside each day's folder (`day1/` .. `day4/`) in a browser.

## 5. Environment Variables

None required.

## 6. Usage and Main Features

- Four folders (`day1/`, `day2/`, `day3/`, `day4/`), each holding that day's advanced JavaScript exercises.

## 7. Screenshots / Demo

No demo; run the HTML files locally.

## 8. Running Tests

No automated tests in this repo.
